# Agent 的不足与「学生必须自己完成」的决策

> 呼应汇报要求第 (5) 条：**Agent 有哪些不足，哪些决策仍然必须由学生自己完成？**
>
> 本文档不是"找借口"，而是诚实地画出 AI 的能力边界。一个负责任的职业规划
> Agent，恰恰要清楚"哪些事我算得清楚、哪些事必须你自己拍板"——把决策权
> 交还给学生，本身就是这个产品最重要的设计理念。

---

## 一、Agent 的不足（诚实清单）

### 1. 数据是"静态快照"，不是"实时市场"

- 招聘样本是**手工摘录的静态 JSON**，不是实时抓取。市场在变（新技术栈、学历门槛涨跌），当前 8 条样本只能代表"某个时间点的抽样"。
- 技能词表、课程库、活动库同样是人维护的，**时效和覆盖面都有限**。
- **后果**：Agent 给出的"核心硬性技能"，只能反映这批样本，不能宣称是"全网岗位的客观结论"。

### 2. 排程是"规则启发式"，不是"最优解"

- 排程用**贪心 + 优先级排序**（技术核心优先、先修拓扑、工时预算），是"一个合理的可行解"，**不是数学意义上的最优解**。
- 它没有考虑：个人学习曲线的非线性、两门课同时进行的认知负担、竞赛/实习的报名时间窗、身体与精力的波动。
- **后果**：路线图"大致靠谱、可执行"，但具体到"这学期先学 A 还是 B"，仍需要人的判断微调。

### 3. 软技能/通用能力缺少"客观评测"

- 沟通、自驱、责任心这类软技能，Agent 只能通过"活动完成 + 成果证据"间接背书，**无法真正测量**。
- "英语六级 550 分"能打分，"沟通能力强"没有客观刻度。
- **后果**：Agent 对软技能的评估偏"自我报告"，可信度低于硬性技术技能。

### 4. 无法替你判断"价值与兴趣"

- Agent 能算出"AI 岗硕士门槛高、建议读研"，但它**不知道你喜不喜欢算法、家里经济能不能支持读研、你更看重稳定还是高薪**。
- 这些是**价值判断**，不是数据能回答的。

### 5. 本地小模型的局限

- 无独显的机器跑本地千问，**速度慢、理解力弱于云端大模型**，工具调用有时选不准。
- 已经通过"确定性路由 + 规则提取"缓解，但自由对话的体验仍明显弱于云端大模型。

## 二、哪些决策「必须由学生自己完成」

这是本文档的重点。Agent 把**可验证的计算全部做完**，但以下决策**刻意留白**，交给学生：

| 决策 | 为什么必须你自己做 | Agent 只做什么 |
|---|---|---|
| **选哪个目标岗位** | 涉及兴趣、性格、家庭、地域、薪资偏好，是价值判断 | 把每个岗位的真实要求、学历门槛、能力缺口算清楚供你对比 |
| **就业 / 考研 / 保研** | 涉及经济成本、家庭期望、个人抗压能力、机会成本 | 给出三条路径的**时间分配差异**和"硕士门槛占比"的客观提示 |
| **优先学哪个技能** | 兴趣 vs 市场需求的权衡，只有你自己能定 | 给出"频次 + 硬性程度 + 先修依赖"的优先级排序，供你参考 |
| **是否接受某条学习路径** | 能否坚持刷题、能否接受高强度投入，是自我认知 | 把每项活动的工时、先修、验收标准写清楚 |
| **"已掌握"的真实性** | 只有你自己知道是不是真会，还是"看过教程" | 要求填写成果证据，但证据的真伪无法核验 |
| **职业价值观排序** | 稳定、高薪、兴趣、成长空间……权重在你 | 不替你排序，只提供事实 |

---

## 三、这个"留白"为什么是优点（答辩要点）

很多学生作品会试图让 AI"全包"——从选岗到排课到做决定。但本题的命题是**"设计属于大学生自己的职业发展 Agent"**，"属于自己"的关键，恰恰是：

> **Agent 是"能力放大器"，不是"人生替身"。它把信息处理、差距计算、路径推演这些苦活做掉，把"选择权"完整地还给学生。**

这三点是答辩时最能体现"职业规划思考深度"的表述：

1. **计算归 Agent，判断归学生** —— 与"模型只理解、计算程序化"的技术设计一脉相承，是技术理念在职业伦理上的延伸。
2. **不留假的确定感** —— Agent 明确标注"频次≠门槛""证据待评估""样本有限"，不制造"这是最优人生方案"的幻觉。
3. **决策权的让渡是刻意设计** —— 那些"必须学生自己做"的决策，不是能力不够，而是**故意不越界**。这正是负责任的 AI 职业规划应该有的样子。

---

## 四、一句话总结

**这个 Agent 能告诉你"路在哪里、每条路要付出什么"，但"走哪条路"，永远是你自己的选择。**
